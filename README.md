## ✨ Features
1. **Seamless Hero Video Loop (`hero-loop.mp4`):**
   - 10-second ultra-smooth 30fps Ken Burns loop showcasing 4 signature photographic styles (Muhurtham ceremony, Courtallam waterfalls, Cinematographer in action, and Studio bridal portrait).
   - High-contrast typography with clear framing allowing full visibility of couples and camera work.

2. **Direct Lead Capture via WhatsApp:**
   - Pre-filled custom Tamil & English WhatsApp inquiry message (`"Vanakkam Shameer sir, I saw your photography portfolio and would like to check availability for our upcoming wedding."`).
   - Sticky conversion-focused actions across Desktop and Mobile.

3. **Pure Zero-Build Static Architecture:**
   - Built with React 18, Babel Standalone, and Tailwind CSS.
   - Hosted natively on **GitHub Pages** with global CDN caching and HTTPS.
